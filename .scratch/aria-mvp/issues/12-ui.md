# 12 — UI: conversation, streaming, tool cards, approvals, todos, undo, search

Status: done

## What

Vite + TypeScript UI: conversation list, new conversation (folder picker via
Tauri dialog), message pane with streaming text and Tool Call cards (args, result,
error state), Approval prompt showing the Edit diff / full shell command / URL,
todo panel, Undo button per changed file, cancel and continue buttons, global
FTS5 search box that jumps to the matching message, settings screen.

## Acceptance

- A full task can be driven end to end with mouse and keyboard only.
- An Approval for an Edit shows the actual search/replace content, not a
  summary.
- Search results open the conversation scrolled to the message.
- No UI state needed to reconstruct a Run lives only in the webview.
